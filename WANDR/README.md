# WANDR — AI Travel Itinerary Planner

> Your destination. Your style. Your plan — in 2 minutes.

## About
WANDR is an AI-powered travel planning web application 
built using Lovable (vibe coding). The entire frontend 
and backend was generated through natural language prompts 
— no manual code written.

## Live App
https://travelwithwandr.lovable.app

## Problem
Travel planning is slow, fragmented, and overwhelming. 
Travelers spend hours switching between blogs, maps, 
YouTube videos, and spreadsheets just to build a basic 
itinerary.

## Solution
WANDR transforms a destination idea into a complete 
personalized travel plan in under 2 minutes including:
- Day-by-day itineraries
- Hidden gems and food recommendations
- Packing lists and safety tips
- PDF export and shareable trip links

## Tech Stack
- Lovable (vibe coding platform)
- Google Gemini / GPT
- React + TypeScript
- Tailwind CSS
- Supabase

## How It Was Built
This project was built entirely through vibe coding 
using Lovable — describing features in plain English 
and letting AI generate the full application. 
No manual coding required.

## Key Decision
Chose Lovable over traditional development to demonstrate 
how AI tools can ship a full production web app faster 
than conventional coding workflows.
